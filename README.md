# TravelTrucks

TravelTrucks, karavan kiralama alanında faaliyet gösteren bir şirket için geliştirilmiş web uygulamasıdır.

## Temel Özellikler

- Karavan listesi ve detay sayfaları görüntüleme
- Backend entegrasyonlu araç filtreleme (Konum, Araç Tipi, Ek Özellikler)
- Sayfalandırma (Load More) işlevi
- Seçili karavanları favorilere ekleme (Local Storage destekli)
- Kullanıcı yorumları ve derecelendirme gösterimi
- Karavan rezervasyon formu

## Kurulum ve Kullanım Talimatları

1. Repoyu bilgisayarınıza klonlayın:
   `git clone <repo-url>`
2. Proje klasörüne gidin:
   `cd travel-trucks`
3. Gerekli bağımlılıkları yükleyin:
   `npm install`
4. Geliştirme sunucusunu başlatın:
   `npm run dev`

## Kullanılan Teknolojiler

- React
- Vite
- React Router DOM
- Redux Toolkit
- Axios
